# Recipe Management System

This project is a **full-stack recipe management application** developed using **ASP.NET Core** for the backend and **React (Vite)** for the frontend.

The system allows users to manage recipes and ingredients through a RESTful API and a modern, component-based user interface.  
The project is structured as a **monorepo**, clearly separating backend and frontend responsibilities while keeping them in a single repository.

---

## Project Description
The backend is designed with a **layered architecture**, separating business logic, data access, and domain models to ensure maintainability and scalability.  
The frontend consumes the API and provides an interactive interface for recipe listing, creation, and management.

This project demonstrates real-world full-stack development practices, including clean project structure, API-driven design, and modular frontend development.

---

## Backend

- Layered architecture (Business, Data, Models)
- Entity Framework Core
- DTO-based data transfer
- SQL-based persistence
